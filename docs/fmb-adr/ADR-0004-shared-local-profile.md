# ADR-0004：共用本機瀏覽器 Profile 支援人機共乘

- **狀態**：現行設計
- **範圍**：瀏覽器 Profile、無頭與有頭模式

## 背景

專案提供背景無頭瀏覽與可見 GUI 瀏覽器兩種工作方式。啟動腳本使用同一個 `profile-agent` 路徑啟動瀏覽器；專案文件描述人類可在有頭模式完成登入或人工驗證，再由 Agent 繼續操作。`tools/profile-init.js` 亦會依平台尋找本機瀏覽器 Profile 資料並進行初始化或同步。

## 決策

- Agent 瀏覽器使用專案管理的本機 Profile，而不是每次執行都建立全新的暫存瀏覽器 Profile。
- 有頭與無頭啟動共用該 Agent Profile，以支援人類與 Agent 接續使用同一瀏覽器狀態。
- 啟動器負責選擇瀏覽器與模式；頁面操作則由共用的 JavaScript、SDK 與 CDP 路徑處理。

## 取捨

- **優點**：登入狀態與瀏覽器工作階段可留在使用者本機；可在可見 GUI 與背景自動化之間切換。
- **代價**：Profile 含有使用者的瀏覽器狀態，必須視為敏感資料，不能放入版控、測試輸出或一般診斷日誌。
- **代價**：兩個瀏覽器程序不能安全地同時以同一 Profile 運作；切換模式需要妥善處理既有程序與檔案鎖。
- **代價**：同步其他瀏覽器 Profile 可能覆蓋或改變本機資料，初始化工具應在了解其作用後才執行。

## 後果

- 修改啟動、停止或模式切換時，檢查 Profile 是否共用、既有程序是否已關閉，以及鎖定檔處理是否符合平台行為。
- 測試應使用隔離的測試 Profile；避免接觸開發者平常使用的瀏覽器資料。
- 不要將 Cookie、登入狀態、網站內容或其他使用者資料加入文件、fixture、截圖或測試報告。
