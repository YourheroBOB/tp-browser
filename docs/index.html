// 02 CORE_VALUES

三大核心價值，重新定義 Agent 瀏覽器

從資料主權、Token 經濟學到人機協作 —— 每個設計決策都為「Agent 與人類共用同一座瀏覽器」而生。

VALUE_01

Cookies 與金鑰 100% 自持主權

零雲端肉機上傳、零第三方伺服器過水。3,371+ 登入態 Cookies（含 HttpOnly）100% 保存在使用者本機（0600 權限與 Windows ACL 鎖定），支援一鍵跨機加密匯出 / 匯入。

VALUE_02

單 Turn 批次 JS，狂省 95%+ Token

告別傳統 Playwright MCP / Computer Use 每步截圖與全頁 DOM 快照的 Token 黑洞。Agent 透過 Heredoc 單次提交完整非同步腳本（tp-browser nodejs）：自動捲動破除懶加載、DOM 萃取、認證下載一氣呵成。

VALUE_03

TaskSpace 人機共乘 Co-Riding

平常無頭背景常駐（tp-start，零焦點搶占、零彈窗干擾）；遇 Cloudflare 驗證或 2FA 登入時，一行指令切換有頭視窗（tp-headed）由人類接手，完成後無縫交還 Agent。
